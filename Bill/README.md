# Bill Split Calculator 

This is a small Python program that helps calculate how much each person should pay when splitting a bill. It takes the total bill amount, adds a tip, and divides the final amount evenly among a group of people.

It's a simple beginner-friendly script and a good example of using **user input, basic math, and formatted output in Python**.

---

## How It Works

The program asks the user for three things:

1. The **total bill amount**
2. The **tip percentage** (for example: 10, 12, or 15)
3. The **number of people splitting the bill**

It then:
- Adds the tip to the bill
- Divides the total by the number of people
- Displays how much each person needs to pay

The result is rounded to **2 decimal places** so it looks like a proper currency value.

---

## Example
```
Welcome to the bill calculator!
What was the bill? $116
What was the tip percentage? 10, 12 or 15 12
How many people to split the bill? 4
Each person should pay: $32.48
```
# How to Run

1. Run the program using:
````
bill_calculator.py
````
2. Follow the prompts in the terminal to calculate the bill.
