# Python Cinema Ticket System 

This is a simple Python program that simulates buying a movie ticket.
The user selects a movie, the program checks age requirements, and then calculates the final ticket price with optional snacks.
---
## How It Works

1. The user chooses a movie from the list.
2. The program checks if the movie has an age restriction.
3. If required, the user enters their age.
4. The program shows the ticket price.
5. The user can optionally add popcorn or a drink.
6. The final bill is calculated and displayed.
