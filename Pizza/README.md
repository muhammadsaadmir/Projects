# Python Pizza 

This is a simple Python program that simulates ordering a pizza.
The user chooses a pizza size and can optionally add pepperoni and extra cheese. The program then calculates the final bill.
---
## How It Works

1. The user selects a pizza size (Small, Medium, or Large).
2. The user chooses whether to add pepperoni.
3. The user chooses whether to add extra cheese.
4. The program calculates and displays the total price.
---
## Pizza Prices

| Size   | Price |
| ------ | ----- |
| Small  | $15   |
| Medium | $20   |
| Large  | $25   |
---
### Toppings

* Pepperoni: +$2 (Small), +$3 (Medium/Large)
* Extra Cheese: +$1
---
## Example

```
Welcome to Python Pizza
What size pizza do you want? Small, Medium or Large? medium
Do you want pepperoni? Y/N Y
Do you want cheese? Y/N Y

Your bill is 24
```
